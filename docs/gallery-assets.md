# Visuels de la galerie — 15 octobre 2026

Six illustrations générées avec l’outil intégré imagegen, mode par défaut, sans API/CLI externe. Les deux captures fournies par l’utilisateur servent de références de composition UI ; elles ne sont pas copiées dans les visuels. Ces scènes fictives ne représentent pas le Musée de Bondoukou ni ses collections. Cette limite est indiquée dans la page et les textes alternatifs.

Les fichiers finaux sont dans `apps/web/public/images/gallery/` : `sculpture.webp`, `archives.webp`, `contemporary.webp`, `photography.webp`, `exhibition.webp`, `art.webp`. Les PNG originaux restent dans le dossier de génération de Codex ; les fichiers consommés par le site sont conservés dans le dépôt. Export WebP à 1000 px de large maximum, sans agrandissement ni recadrage, qualité 82, avec sharp déjà disponible via Next.js. Les deux illustrations existantes du hall et du livre sont réutilisées sans modification pour compléter la mosaïque de huit images.
